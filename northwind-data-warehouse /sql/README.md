# SQL Scripts

This folder contains all SQL scripts for creating and loading the Northwind Data Warehouse.

## Files

| File | Description |
|------|-------------|
| `00_create_database.sql` | Create the Northwind_DW database |
| `01_create_dimensions.sql` | Create all dimension tables |
| `02_create_fact.sql` | Create the fact table |
| `03_load_dim_customer.sql` | Load dim_customer |
| `04_load_dim_product.sql` | Load dim_product |
| `05_load_dim_employee.sql` | Load dim_employee |
| `06_load_dim_shipper.sql` | Load dim_shipper |
| `07_load_dim_date.sql` | Load dim_date |
| `08_load_fact_sales.sql` | Load fact_sales |
| `09_etl_master.sql` | Master ETL script |
| `10_validation_queries.sql` | Data validation queries |
